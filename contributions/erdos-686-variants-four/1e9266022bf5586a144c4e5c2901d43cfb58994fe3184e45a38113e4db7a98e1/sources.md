# Provenance and intended use

Original Lean formalization developed in this research chat with OpenAI Codex assistance. The signer remains responsible for the work. This supplies the complete length-six exclusion for [Erdős 686](https://www.erdosproblems.com/686), ratio 4.

The intended use is `no_ratio_four_six`, whose conclusion has the rational-product form of the [pinned target](https://github.com/conjectures-io/conjectures-tasks/tree/2a58149e6edb0f1dc15b32391f8c29fdd85e9db3/pool/tier-1/erdos-686-variants-four-counterexample). It discharges the k=6 case under the target's disjointness hypothesis n+6 <= m.

Write F(n)=(n+1)...(n+6), P(n)=16n^3+168n^2+518n+441 and C(n)=756n^2+5292n+10161. The checked identity P(n)^2-256F(n)=C(n), positivity and 2C(n)<P(n) for n>=247 force P(m)=2P(n) whenever F(m)=4F(n) and m>=n>=247. This contradicts oddness of P(m). The theorem `solution_lower_start_le_246` exposes the resulting bound.

For n=0,...,246, the `cut` table supplies a candidate bracketing index. `finite_certificate` verifies every entry by Lean kernel reduction. Monotonicity then proves `finite_check`: the only product equality in this range is n=1,m=2. Disjointness excludes it. The candidate table was generated by Python integer arithmetic; the proof trusts only Lean's check of its inequalities, not the generator. No native computation axiom is used.

The existing [target contributions](https://github.com/conjectures-io/conjectures-contribution/tree/4ed0217e9791408469af21821d37e3a0aa31bef1/contributions/erdos-686-variants-four) were checked on 2026-11-03: they address lengths 2,3,4 and a bounded search, not the all-n length-six theorem. This proof is independent and imports no earlier contribution. No parent contribution was used.

The square-approximation approach was explored in the prior sessions of this chat and compared with the [public discussion](https://www.erdosproblems.com/forum/thread/686). We claim a reusable missing formalization, not priority for the general method. [Mathlib](https://github.com/leanprover-community/mathlib4/tree/0df444a360eaa60ab8c11dca51a86af692955474) supplies the arithmetic tactics and finite-product API. This does not settle the unrestricted target.
