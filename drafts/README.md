# drafts

Working area for contributions that have not been promoted yet. Everything here is
ignored by git except this file and `.gitignore`.

```
contrib new erdos-100      # scaffolds drafts/erdos-100/
contrib promote erdos-100  # hashes, signs, writes contributions/erdos-100/<id>/
```

`draft.json` carries the fields you choose; every other file in the directory becomes an
artifact of the contribution. `sources.md` is required.
